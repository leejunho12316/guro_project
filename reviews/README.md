# 동네 리뷰 데이터

구디 월세방 지도의 '💬 리뷰' 모드에 쓰인 커뮤니티 글 조사 데이터예요. (수집: 2026-11-09 ~ 11-10)

- `all_reviews.json` — 지도에 실린 글 1024개 전체 (플랫폼, 링크, 제목, 날짜, 동네, 세부 구역, 주제, 긍·부정, 본문+댓글 요약, 읽은 댓글 수)
- `areas.json` — 동네·세부 구역별 이름, 키워드 3개, 요약, 경계(GeoJSON)
- `raw/gudi/` — 구로디지털단지역 일대 플랫폼별 원본 수집 파일
- `raw/sindorim/` — 신도림역 일대 플랫폼별 원본 수집 파일

글 본문·댓글 원문은 저장하지 않았고, 읽고 요약한 내용과 원문 링크만 있어요.
